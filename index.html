About the data

Every dataset in this course is real and traces to a named public source — the Pennsylvania Department of Health, the CDC, or the EPA. County-level figures are reported as published, including their suppression rules and known limitations.

Submitting a lab

Each lab has a notebook to submit alongside it. Download that .ipynb, open it in Colab (File > Upload notebook), and work the exercises there. It carries the same worked examples and the same tasks as the lab on this site, so work can be moved across either by copying from the browser or by typing it directly into the notebook.

Run the setup cell at the top first — it downloads the lab’s data files from this site. Nothing to upload, and no Google Drive needed. Submit the completed .ipynb.

Homework

One homework per module, due the Monday after the lab. Each is a single public-health question broken into parts, and each part exercises something taught in that module’s lecture and lab.

Homework notebooks give you the code that loads the data and nothing else — you write the rest from an empty cell. That is the difference between a lab and a homework: labs are scaffolded so a room can move together, and homework is where the scaffold comes off.

Every homework ends with a written interpretation. It is graded as heavily as the code. A correct number with nothing said about what it means is an incomplete answer.

Work in Colab, then submit the saved notebook: File > Download > Download .ipynb. Make sure your outputs and figures are visible in the file you upload. Pairs are allowed.

Software

Coursework is completed in Google Colab. The slides on this site run Python directly in the browser through Pyodide, which requires no account and no installation.
