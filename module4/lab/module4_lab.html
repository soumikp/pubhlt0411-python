Two facts that recur throughout

A rate is deaths / population * 100000. A blank is suppression, not zero — a count too small to publish. Neither region nor metro appears in any outcome file, so every grouped comparison below requires a join.

Exercise 12 — The suppression bias

Exercise 12 — The suppression bias

Worked example. A grouped rate divides summed deaths by summed population. .sum() skips NaN — but the population denominator still counts every county.

Exercise 12 — The suppression bias — your turn

Your turn. Recompute the Northwest rate over the counties that actually reported, and measure the bias. Drop the suppressed rows before summing.

# The blank is dropna. `subset=` restricts the drop to rows missing that one
# column, rather than dropping any row with a gap anywhere.
# The naive figure is 37.5 and the correct one is 39.5, so the naive rate
# understates the Northwest by 2.0 per 100,000.
# The suppressed counties contributed population but no deaths.
import pandas as pd overdose = pd.read_csv("data/pa_overdose_county_year.csv") counties = pd.read_csv("data/pa_counties.csv") o = overdose[overdose["year"] == 2023].merge(counties, on="county", how="left") nw = o[o["region"] == "Northwest"] naive = nw["overdose_deaths"].sum() / nw["population_2023"].sum() * 100_000 reported = nw.dropna(subset=["overdose_deaths"]) correct = reported["overdose_deaths"].sum() / reported["population_2023"].sum() * 100_000 print(f"Naive: {naive:.1f} per 100,000 (denominator: {len(nw)} counties)") print(f"Correct: {correct:.1f} per 100,000 (denominator: {len(reported)} counties)") print(f"Bias: {naive - correct:.1f}") 
import pandas as pd

overdose = pd.read_csv("data/pa_overdose_county_year.csv")
counties = pd.read_csv("data/pa_counties.csv")

o = overdose[overdose["year"] == 2023].merge(counties, on="county", how="left")
nw = o[o["region"] == "Northwest"]

naive = nw["overdose_deaths"].sum() / nw["population_2023"].sum() * 100_000

reported = nw.dropna(subset=["overdose_deaths"])
correct = reported["overdose_deaths"].sum() / reported["population_2023"].sum() * 100_000

print(f"Naive:   {naive:.1f} per 100,000  (denominator: {len(nw)} counties)")
print(f"Correct: {correct:.1f} per 100,000  (denominator: {len(reported)} counties)")
print(f"Bias:    {naive - correct:.1f}")

A silent error, largest where it matters most

No exception is raised and the naive figure looks reasonable. The bias runs downward and is largest in rural regions, which is exactly where suppression concentrates.

The rule: whenever a ratio is computed over a group, confirm the numerator and the denominator cover the same rows.

Exercise 14 — Repair a broken key

Exercise 14 — Repair a broken key

This join is broken. Run it, read the output, and repair it.

County Health Rankings publishes one county as “Mc Kean”; the Census file writes “McKean”. The two strings differ by one space, so the row does not match.

# This cell is already correct — run it and confirm n_unmatched is 0.
# Then break it: delete the .assign(...) step and join `external` directly.
# McKean comes back with NaN population, and n_unmatched becomes 1.
#
# The lesson is the CHECK, not the fix. A NaN in a column that came from the
# right-hand table means either a real gap or a broken key, and those need
# different repairs. An inner join would have deleted the row silently
# instead of flagging it.
import pandas as pd counties = pd.read_csv("data/pa_counties.csv") external = pd.DataFrame({ "county": ["Mc Kean", "Potter", "Tioga"], "clinics": [3, 2, 4], }) fixed = external.assign( county=lambda d: d["county"].str.replace(" ", "", regex=False) ) joined = fixed.merge(counties[["county", "population_2023"]], on="county", how="left") n_unmatched = joined["population_2023"].isna().sum() print(joined) print(f"\nUnmatched rows: {n_unmatched}") 
import pandas as pd

counties = pd.read_csv("data/pa_counties.csv")

external = pd.DataFrame({

    "clinics": [3, 2, 4],

A failed match is not missing data

McKean County’s population is published and known. It was absent because the key did not match. Count the NaNs in a borrowed column after every join — the two causes look identical in the output and require different fixes.

Exercise 16 — Chain the pipeline

Exercise 16 — Chain the pipeline

Worked example. Each method returns a DataFrame, so the next attaches to it. The outer parentheses let the chain break across lines.

Exercise 16 — Chain the pipeline — your turn

Your turn. Build the full pipeline: take 2023 overdose data, attach the region, drop the suppressed counties, and summarise by region.

# The blank is groupby.
# Read the chain top to bottom as a sentence: take 2023, attach the region,
# drop the suppressed counties, group by region, summarise, sort, round.
# The `reporting` column is the denominator and it belongs in the output —
# Southwest's mean covers 11 counties, Northeast's only 7.
# Southwest is highest at 36.0 per 100,000; South Central lowest at 20.7.
import pandas as pd overdose = pd.read_csv("data/pa_overdose_county_year.csv") counties = pd.read_csv("data/pa_counties.csv") summary = ( overdose .query("year == 2023") .merge(counties, on="county", how="left") .dropna(subset=["overdose_deaths"]) .groupby("region") .agg(reporting=("county", "size"), mean_rate=("rate_per_100k", "mean")) .sort_values("mean_rate", ascending=False) .round(1) ) print(summary) 
import pandas as pd

overdose = pd.read_csv("data/pa_overdose_county_year.csv")
counties = pd.read_csv("data/pa_counties.csv")

summary = (
    overdose
    .query("year == 2023")
    .merge(counties, on="county", how="left")
    .dropna(subset=["overdose_deaths"])
    .groupby("region")
    .agg(reporting=("county", "size"), mean_rate=("rate_per_100k", "mean"))
    .sort_values("mean_rate", ascending=False)
    .round(1)
)

print(summary)

Two cautions on chaining

A chain has no intermediate variable to inspect, so debug it by commenting out the tail and running the head. Past six or seven steps, split it into two named pieces.
