Data visualization I

The lecture established that adult asthma prevalence barely varies across Pennsylvania counties — 9.7% to 11.6% — while smoking prevalence varies across eleven points, and that the two move together at +0.659.

This lab builds seven figures from four real files with matplotlib and seaborn, then repairs one figure that runs without error and misleads anyway.

Lab mechanics

  • Each exercise supplies a worked example, then a similar problem to complete.
  • Click into a code block and press Run. Edit the blanks (____) and run again.
  • Hint gives the reasoning. Solution gives the answer.
  • Each exercise takes two slides: the worked example, then the task.
  • Arrow keys navigate between slides.

One of these exercises contains no error message

Exercise 8 supplies a figure that executes cleanly and states something false. A figure that raises no exception has not been checked — it has only been run.

The data

Four real files, all mounted and readable with pd.read_csv().

File Rows Contents
data/pa_asthma_prevalence.csv 67 Asthma, smoking, obesity prevalence — CDC PLACES 2024
data/pa_counties.csv 67 Population, region, metro/nonmetro — the join target
data/pa_maternal_infant.csv 67 Infant mortality, poverty, income — 23 counties suppressed
data/pa_covid_monthly.csv 3,283 COVID deaths by county and month — reliable from mid-2021

Three facts that recur throughout

A rate is deaths / population * 100000. A blank is suppression, not zero. Neither region nor metro appears in any outcome file, so every grouped figure below requires a join first.

The course figure palette

Every colour below was measured against white with the WCAG relative luminance formula. A mark that carries data needs 3:1; text needs 4.5:1.

Colour Ratio Use
#003594 royal 10.84 : 1 The primary series
#8a6400 dark gold 5.38 : 1 The second series
#6b7280 gray 4.83 : 1 Annotation and source notes

No two of these separate from each other by 3:1

Royal against dark gold is 2.02:1. Each is readable against the page; they are not reliably distinguishable from one another. Every two-series figure in this lab therefore carries a second channel — a marker shape, a dash pattern, or a direct label.

import micropip                                            # installer for browser packages
await micropip.install("seaborn")                          # fetch seaborn
import pandas as pd                                        # tables
import seaborn as sns                                      # statistical figures
import matplotlib.pyplot as plt                            # figure and axes

covid = pd.read_csv("data/pa_covid_monthly.csv")           # deaths by county and month
counties = pd.read_csv("data/pa_counties.csv")             # population and metro per county
covid["month"] = pd.to_datetime(covid["month"])            # text -> real dates
covid = covid[covid["month"] >= "2021-08-01"]              # keep the reliably reported period

merged = covid.merge(counties[["county", "population_2023", "metro"]],  # attach population
                     on="county")                                       # and metro status
monthly = (merged.groupby(["month", "metro"], as_index=False)           # one row per month x group
                 [["covid_deaths", "population_2023"]].sum())           # total deaths and people
monthly["per_100k"] = (monthly["covid_deaths"]             # deaths ...
                       / monthly["population_2023"]        # ... per resident ...
                       * 100000)                           # ... per 100,000

fig, ax = plt.subplots(figsize=(8, 3))                     # canvas and one axes
sns.lineplot(data=monthly, x="month", y="per_100k",        # data; time -> x, rate -> y
             hue="metro", style="metro",                   # metro -> colour AND dash pattern
             palette={"Metro": "#003594",                  # course colours, by group
                      "Nonmetro": "#8a6400"},              # dark gold for nonmetro
             linewidth=2, ax=ax)                           # SETTING: line width; target axes
ax.set(xlabel="Month",                                     # x-axis label
       ylabel="COVID-19 deaths per 100,000")               # y-axis label with units
ax.get_legend().set_title("Metro status")                  # legend title
plt.tight_layout()                                         # keep labels inside the canvas
plt.show()                                                 # render the figure

peaks = monthly.loc[monthly.groupby("metro")["per_100k"].idxmax()]   # each group's worst month
print(peaks[["metro", "month", "per_100k"]].round(1).to_string(index=False))  # print the peaks

import pandas as pd                                        # tables
import matplotlib.pyplot as plt                            # plotting

asthma = pd.read_csv("data/pa_asthma_prevalence.csv")      # one row per county
counties = pd.read_csv("data/pa_counties.csv")             # region per county
joined = asthma.merge(counties[["county", "region"]],      # attach region ...
                      on="county", how="left")             # ... keeping every county

by_region = (joined.groupby("region")["asthma_prev_pct"]   # one mean per region ...
                   .mean().sort_values())                  # ... in ascending order

fig, ax = plt.subplots(figsize=(7, 3))                     # canvas and one axes
ax.bar(by_region.index, by_region.values, color="#003594") # one bar per region
ax.set_ylim(0, 12)                                         # the baseline a bar requires
ax.set_ylabel("Mean adult asthma (%)")                     # y-axis label with units
ax.set_title("Mean county asthma prevalence by region")    # a title that describes the chart
ax.tick_params(axis="x", labelrotation=30, labelsize=7)    # tilt and shrink region names
plt.tight_layout()                                         # keep labels inside the canvas
plt.show()                                                 # render the figure

spread = by_region.max() - by_region.min()                 # highest mean minus lowest
print("baseline:", ax.get_ylim()[0])                       # the repaired lower limit
print("true spread across six regions:", round(spread, 2), "percentage points")  # the real gap
