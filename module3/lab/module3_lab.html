Parallel arrays are aligned by convention only

counties[12] and pm25[12] describe the same county because they were read from the same rows. Nothing in the code enforces that. Sorting one array without the other silently destroys the correspondence — which is the problem the DataFrame in Module 4 solves.

Exercise 5 — Standardise

Exercise 5 — Standardise

Worked example. A z-score is the distance from the mean in standard deviations.

Exercise 5 — Standardise — your turn

Your turn. Standardise all 67 counties (use the default .std(), as in Exercise 2) and identify the outlier: the county with the largest z-score.

# The blank is std — the standard deviation, which is what a z-score divides by.
# .argmax() gives the position of the largest value, not the value itself,
# and that position indexes the names array.
# Allegheny comes out at +4.37, which is an extraordinary distance from typical.
import numpy as np counties = np.genfromtxt( "data/pa_air_pollution.csv", delimiter=",", skip_header=1, usecols=0, dtype=str ) pm25 = np.genfromtxt( "data/pa_air_pollution.csv", delimiter=",", skip_header=1, usecols=1 ) z = (pm25 - pm25.mean()) / pm25.std() worst_position = z.argmax() worst_county = counties[worst_position] worst_z = z[worst_position] print(f"Highest: {worst_county} at z = {worst_z:+.2f}") print(f"Counties above z = 2: {counties[z > 2]}") 
import numpy as np

counties = np.genfromtxt(
    "data/pa_air_pollution.csv", delimiter=",", skip_header=1, usecols=0, dtype=str
)
pm25 = np.genfromtxt(
    "data/pa_air_pollution.csv", delimiter=",", skip_header=1, usecols=1
)

z = (pm25 - pm25.mean()) / pm25.std()

worst_position = z.argmax()
worst_county = counties[worst_position]
worst_z = z[worst_position]

print(f"Highest: {worst_county} at z = {worst_z:+.2f}")
print(f"Counties above z = 2: {counties[z > 2]}")

A z-score compares within a collection

Allegheny’s +4.37 states that the county is more than four standard deviations from the typical Pennsylvania county. It does not describe a health effect, and it applies to a county-wide annual average — concentrations vary widely within any single county.

import numpy as np

# 2023 overdose rates per 100,000. nan marks a suppressed county —
# fewer than ten deaths, so the state withholds the figure.
rates_2023 = np.array([
    54.7, 84.8, 41.7, 4.4, 62.1, 50.5, np.nan, 43.4,
    42.8, np.nan, 26.8, np.nan, 31.2, 19.6, np.nan,

Report the denominator

np.nanmean() describes the counties that reported, not the state. Suppression concentrates in small rural counties, so the counties omitted are not a random sample. “42.0 per 100,000 across the 11 counties that reported” is the honest statement; the figure alone is not.

Exercise 8 — Find the error

This code is broken. Run it, read the error, and repair it.

The objective is to count the counties that exceed the standard but stay below 11.0.

# ValueError: the truth value of an array with more than one element is ambiguous.

# The answer is 20 counties.

    "data/pa_air_pollution.csv", delimiter=",", skip_header=1, usecols=1

ValueError — and cannot reduce an array to one truth value

and and or require a single true-or-false value. A comparison on a 67-element array produces 67 of them, and Python refuses to guess which one was meant.

Resolution: & and | combine masks element by element. Each comparison needs its own parentheses, because & binds more tightly than >.
